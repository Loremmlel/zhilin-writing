# 全站 UI 合理性审计清单（2026-09-08）

## 目的

记录本轮针对知临中学全站的 UI/UX 合理性审计结论和用户取舍，作为后续修复的唯一范围清单，避免遗漏、重复讨论或把已驳回事项重新包装后实施。

本次审计不只检查按钮，还覆盖：信息层级、布局、响应式、状态反馈、文案语义、可访问性、加载几何、错误恢复和跨页面一致性。

## 执行约束

- 以现有 `DESIGN.md` 和 `UX-CONTRACT.md` 为准，保留温暖纸面、校园绿和长文阅读气质。
- 只做表格中记录的最小修复，不引入新依赖，不重做设计系统，不替换编辑器，不引入 DataGrid。
- 优先复用现有组件和 CSS；不要为了统一而新建复杂抽象。
- 已驳回项目不得实施，除非用户之后明确重新批准。
- 本轮审计基于源码和静态布局。实施后执行格式、类型、单元测试、构建和静态 UI 审计；真实浏览器与视觉验收由部署后人工完成。
