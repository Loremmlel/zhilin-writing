# 帖子可见白名单

依据：2026-09-19 用户要求，在发布/编辑帖子时选择站内用户，管理员不显示且始终可见。

- 默认全部站内用户可见，既有帖子不改变；指定用户时作者自动加入，空选择仅作者与管理员可见。候选只含已完成资料且仍具站点访问权限的普通用户，不暴露邮箱。
- 单个 JSON 列保存小型受邀社区的成员 ID；所有公开查询用同一服务端谓词，在分页/计数前过滤。管理员身份来自站内授权表。
- 回复、批注、个人动态、通知/未读计数、标签与资源访问继承帖子范围；附件不再长时间缓存。修改范围产生新版本并沿用冲突检查；管理员恢复正文不恢复历史权限。
- 普通编辑器与 DOCX 发布共用选择组件，本地草稿保留范围；旧客户端缺失字段时保留现有范围。
- 验证：迁移 SQLite 上执行生产查询，覆盖获准/未获准/管理员、收紧与放开、分页计数、通知、附件、非法选择；运行类型检查、相关行为测试与构建。
