# 普通组与游戏组

2026-09-20，来源：本轮用户权限组需求。

- `allowed_users.permission_group` 是权限组唯一来源，值为 `normal` / `game`。新增常量默认 `normal` 的非空列，已有受邀邮箱（含尚未注册的邮箱）自动为普通组；不复制到用户资料或浏览器凭据。
- 唯一管理员保持原有完整权限，不允许通过分组操作修改管理员。邀请默认普通组，可选择游戏组；既有邀请在成员表中确认修改。
- 普通组保留现有访问能力。游戏组可访问浩劫大厅、自己的房间、编辑自己的资料及自己的头像；主页与保存资料后进入浩劫大厅。登录、资料初始化、退出、只写诊断通道属于必要辅助能力。
- 游戏组不能访问帖子、回复、批注、搜索、标签、个人动态、通知、导入或管理信息。页面跳回浩劫，写入接口返回 403；授权在服务端执行，不能仅隐藏导航。内容 SQL 额外检查当前组，指定帖子白名单不提升游戏组权限；候选名单排除游戏组。
- 资产接口对游戏组只放行其本人头像，既有帖子附件及临时正文上传同样拒绝。组变更不删除旧内容；每次请求重新读取授权，请求内缓存不跨请求共享。
- 复用 `AccountMenu`、`SiteHeader`、原生单选框、`ModalDialog`、`PendingSubmitButton` 与内联失败反馈；不引入权限管理框架或新依赖。
